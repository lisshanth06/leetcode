# leetcode

A systematic repository of algorithmic design patterns and computational logic. Focuses on memory optimization, rigorous Big-O analysis, and reusable frameworks for high-performance software engineering.

Solutions are organized by DSA pattern rather than by problem name, so related problems sit together.

Empty pattern folders (trees, tries, heap-priority-queue, backtracking, graphs, intervals) will be added as those problems are solved.

A problem that spans multiple patterns is filed under its dominant pattern, with a one-line comment at the top of the solution file noting the secondary pattern (e.g. `linked-list/linked-list-cycle` notes its two-pointers/Floyd's-cycle technique).
